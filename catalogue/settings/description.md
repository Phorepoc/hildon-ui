The Maemo Leste control panel, hildon-control-panel, running on the Hildon package. It comes with five applets:
**Date and time** sets the date, the time and the 12/24-hour clock; **Regional settings** sets the date format; **Display** sets when the screen light turns off;
**Profiles** switches the sound profile (General, Silent, Meeting, ...); **About device** shows the software version, the language, memory and storage.
They read and change the system settings, so the rest of the phone follows.

It needs the Hildon package (and through it GLib, GTK and D-Bus); Catalogue installs those first.

Open it from the menu as **Settings (Hildon)**.
