The libhildon demo shows the Maemo-style widgets of the Hildon package: a pannable list of Hildon buttons, a picker
button with its touch selector, an entry, a check button, the application menu, a banner and a note.

It needs the Hildon package (and through it GLib, GTK and D-Bus); Catalogue installs those first. With the
Hildon theme alpha package installed it draws in the Maemo Leste look, otherwise in a plain GTK style.

Open it from the menu as **Hildon demo**.
