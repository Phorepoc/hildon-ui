A home widget for the Hildon Home (the Maemo Leste desktop): free memory and free storage on C:, each as a number and a bar, refreshed every 30 seconds. The bar turns red when less than a tenth is free.

It needs the Hildon package; Catalogue installs it first. To show it, open Home (Hildon) from the menu, hold a finger on the Home until edit mode starts, tap Add widget and choose Device status. In edit mode a widget can be dragged to another place.
